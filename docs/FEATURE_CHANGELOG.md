## 变更记录格式

每个功能点的变更记录包含：
- **功能编号**: F-XXX-XXX-vX.X
- **变更日期**: YYYY-MM-DD
- **变更类型**: 新增/修改/废弃/删除
- **变更版本**: vX.X -> vX.X
- **变更原因**: 简要说明
- **影响范围**: 受影响的模块和功能
- **迁移指南**: 如有必要，提供迁移步骤
